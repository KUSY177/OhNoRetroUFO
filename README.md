# OhNoRetroUFO
---
Проект представляет собой ретро‑аркаду, написанную на языке C, с использованием Raylib для рендеринга и Lua для скриптовой логики. Игра построена по модульной архитектуре, что позволяет легко переносить её на разные платформы, расширять функционал, добавлять новые сущности, уровни и механики. Основная цель — создать компактный, понятный и кроссплатформенный игровой движок, который можно запускать на Windows, Linux, macOS и WebAssembly.
---
# Основная идея проекта
---
Игрок управляет кораблём, уклоняется от врагов, взаимодействует с объектами, использует таймеры, систему столкновений и скриптовую логику. Вся игровая механика разделена на независимые модули, что делает проект удобным для изучения, модификации и расширения. Lua используется для описания поведения врагов, волн, параметров уровня и других элементов, которые удобно менять без перекомпиляции.
---
# Архитектура проекта
---
src/core — ядро игры. Здесь находятся файлы, отвечающие за игровой цикл, обновление состояния, обработку ввода, рендеринг, управление ресурсами, таймерами, сущностями и столкновениями.  
src/logic — логика, связанная с Lua. В этом каталоге находятся биндинги, которые позволяют Lua управлять объектами игры, создавать новые сущности, изменять параметры и вызывать функции движка.  
assets — графика, шрифты, звуки, анимации.  
tests — модульные и интеграционные тесты, которые проверяют корректность работы отдельных частей движка.  
CMakeLists.txt — кроссплатформенная система сборки, поддерживающая Windows, Linux, macOS и WebAssembly.  
Makefile — сборка и тестирование на Linux и MinGW.  
LICENSE — лицензия MIT.
---
# Функционал игрового движка
---
Обработка ввода: клавиатура, мышь, базовые события.  
Система сущностей: создание, обновление, удаление, хранение состояния.  
Система столкновений: проверка пересечений, реакция на столкновения, обработка логики.  
Таймеры: задержки, интервалы, события по времени.  
Рендеринг: отрисовка спрайтов, текста, примитивов, интерфейса.  
Ресурсы: загрузка текстур, шрифтов, аудио.  
Lua‑интеграция: вызов Lua‑функций из C, передача данных в скрипты, выполнение логики уровня.  
Игровой цикл: обновление состояния, рендеринг, обработка событий, синхронизация кадров.
---
# Lua в проекте
---
Lua используется для описания поведения врагов, волн, параметров уровня, а также для создания динамических событий. Скрипты могут управлять сущностями, изменять их скорость, направление, здоровье, вызывать функции движка, создавать новые объекты. Это позволяет менять игровой процесс без перекомпиляции и делает проект гибким для моддинга.
---
# Тестирование
---
Модульные тесты проверяют отдельные части движка: столкновения, сущности, базовые функции.  
Интеграционные тесты проверяют работу нескольких систем одновременно: волны врагов, взаимодействие логики и ядра.  
Команда make test запускает все тесты и выводит результат.

# Сборка на Windows (MSYS2 MinGW64)
---
Установка зависимостей:  
pacman -S mingw-w64-x86_64-gcc mingw-w64-x86_64-raylib  
Сборка:  
mkdir build  
cd build  
cmake ..  
mingw32-make  
Запуск:  
./OhNoRetroUFO.exe
---
# Сборка на Linux
---
Установка зависимостей:  
sudo apt install build-essential cmake libraylib-dev lua5.4 liblua5.4-dev  
Сборка:  
mkdir build  
cd build  
cmake ..  
make  
Запуск:  
./OhNoRetroUFO
---
# Сборка под WebAssembly (Emscripten)
---
Установка Emscripten:  
git clone https://github.com/emscripten-core/emsdk.git  
cd emsdk  
./emsdk install latest  
./emsdk activate latest  
source ./emsdk_env.sh  
Сборка:  
mkdir build_web  
cd build_web  
emcmake cmake ..  
emmake make  
Запуск:  
emrun OhNoRetroUFO.html

# Кроссплатформенность
---
Проект поддерживает сборку на всех основных платформах.  
Windows — MinGW64 + Raylib DLL.  
Linux — системные библиотеки Raylib и Lua.  
macOS — сборка через CMake с использованием Raylib для Metal.  
Web — сборка через Emscripten в HTML + JS + WASM.  
Структура проекта позволяет переносить ассеты и исходники без изменений, а зависимости можно хранить в отдельной папке для каждой платформы.
